# Установить УМКУ на новую плату

Нужны плата с 64-битной системой, USB-камера, сеть и учётная запись с правом `sudo`. Для Raspberry Pi 4/5 используйте Raspberry Pi OS Bookworm. Для Orange Pi 5/5B — образ Ubuntu 22.04 для платы. На Raspberry Pi 5 также проверено обновление уже установленной программы на Trixie.

## 1. Подготовить плату

1. Подключите камеру и, если нужен автоматический сброс, [контроллер моторов](../docs/hardware.md). Для полноэкранного режима нужен рабочий стол и подключённый экран.
2. Подключите плату к сети и включите SSH. На Raspberry Pi откройте `sudo raspi-config` и включите SSH в **Interface Options**. На Orange Pi с установленным OpenSSH выполните `sudo systemctl enable --now ssh`.
3. На плате выполните `hostname -I` и запишите её адрес. Узнайте логин, под которым будете входить на плату.

## 2. Установить программу с компьютера

На компьютере нужны Git, Bash и SSH. На Windows команды можно выполнять в WSL. Компьютер и плата должны видеть друг друга по сети.

```bash
git clone https://github.com/aleksioprime/sk-umka.git
cd sk-umka
./manager/menu.sh
```

Введите логин и адрес платы, например `umka@192.168.10.60`.
Если используется обычный вход по SSH, нажмите Enter в полях ключа и порта.
Выберите **1. Установить УМКУ и окружение**.

Меню определит тип платы и через установщик подготовит системные пакеты,
виртуальное окружение Python, PyTorch и библиотеки УМКИ. Если плата
попросит пароль SSH или `sudo`, введите его в терминале.

Программа появится в `~/app`. Меню включает автозапуск сортировки при включении
платы и полноэкранного окна при входе на рабочий стол. Если установщик попросит
перезагрузку, перезагрузите плату. Для повседневного управления по SSH
используйте [консольное меню](../manager/README.md).

## 3. Проверить запуск и настроить сортировку

1. Откройте на плате ярлык **Открыть экран UMKA** или в браузере на компьютере перейдите по адресу `http://IP-ПЛАТЫ:3000`. Если адрес изменился, снова выполните на плате `hostname -I`.
2. Коснитесь логотипа пять раз и откройте **Настройки**. Проверьте камеру и [откалибруйте моторы](../docs/hardware.md#проверить-оборудование).
3. Для ручного запуска, остановки и сбора снимков используйте [инструкцию к программе](../app/README.md).

## 4. Подключить плату к мониторингу

Выберите постоянный ID, например `rpi-classroom-01`. Используйте до 64 символов из латинских букв, цифр, дефисов и подчёркиваний. Для каждого устройства нужен свой ID. После смены IP менять его не нужно.

На плате откройте `~/app/umka.conf`. Например, в терминале:

```bash
chmod 600 ~/app/umka.conf
nano ~/app/umka.conf
```

Добавьте или измените строки подключения. Логин и пароль брокера возьмите у администратора проекта.

```ini
device_id = rpi-classroom-01
mqtt_host = mqtt.skolhub.ru
mqtt_port = 8883
mqtt_tls = yes
mqtt_username = umka
mqtt_password = ВСТАВЬТЕ_ПАРОЛЬ_БРОКЕРА
```

Пароль храните в файле на плате. Если настройки уже содержат один из этих ключей, измените его значение в существующей строке.

1. Войдите как администратор на [сайт мониторинга](https://umka.technocrew.ru/), нажмите **Добавить устройство** и введите этот же ID и понятное имя, например **УМКА в кабинете информатики**.
2. На плате выполните `sudo systemctl restart umka`. При ручном запуске перезапустите программу по [инструкции](../app/README.md#запуск-и-остановка).
3. Откройте карточку нового устройства. Обычно в течение минуты появятся статус **Онлайн** и данные камеры и модели.

Если плата уже прислала статус до регистрации, этот статус можно найти в [журнале MQTT](../web/README.md#добавить-устройство) и зарегистрировать устройство оттуда. После регистрации дождитесь следующего статуса, прежде чем проверять сортировку.

## Обновить уже установленную программу

На компьютере из папки проекта:

```bash
git pull --ff-only
./manager/menu.sh umka@192.168.10.60
```

Выберите **2. Обновить файлы программы**. Настройки, данные и Python-окружение
сохранятся. Если служба настроена, она перезапустится. При ручном запуске
перезапустите программу сами.

<details>
<summary>Команды для установки без меню</summary>

- `deploy/install.sh umka@192.168.10.60 --autostart` — установить на Raspberry Pi.
- `deploy/install.sh orangepi@192.168.10.100 --autostart` — установить на Orange Pi.
- `deploy/install.sh umka@192.168.10.60 --code-only` — обновить файлы программы.
- `deploy/install.sh --help` показывает доступные параметры.
- `--ssh-key ПУТЬ` указывает ключ SSH. Без ключа установка может попросить пароль при подключении.
- `--hardware pca9685` выбирает контроллер моторов. `--hardware console` имитирует сброс. Для Raspberry Pi с прямым подключением используется `--hardware gpiozero`.
- `--tilt-channel 1 --rotate-channel 0` — каналы наклона и поворота по умолчанию. `--camera 0` — камера `/dev/video0`.
- `--i2c-bus N` позволяет задать шину вручную. По умолчанию Raspberry Pi использует `/dev/i2c-1`, Orange Pi 5/5B — `/dev/i2c-5`.
- Если контроллер не определился, проверьте питание и подключение по [схеме](../docs/hardware.md). После проверки можно повторить установку с `--hardware pca9685`.

</details>
