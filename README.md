# УМКА — умная сортировка мусора

УМКА распознаёт предмет по изображению с камеры и отправляет его в одну из четырёх секций. Проект работает на Raspberry Pi 4/5 и Orange Pi 5/5B.

## Запустить готовое устройство

1. Включите плату и экран. Если настроен автозапуск, программа сортировки запустится вместе с платой, а полноэкранный режим откроется при входе на рабочий стол.
2. Если полноэкранный режим не открылся, нажмите ярлык **Открыть экран UMKA**. С компьютера или телефона в той же сети можно открыть `http://IP-ПЛАТЫ:3000`. Например, для Raspberry Pi на стенде это [192.168.10.52:3000](http://192.168.10.52:3000/).
3. Положите один предмет на площадку. Если экран попросит подтвердить тип отхода, нажмите **Да** или **Нет**.

Пять быстрых касаний логотипа открывают меню. Там можно выбрать модель, включить ручной сбор снимков и открыть настройки.

## Добавить новую плату

1. Подключите камеру и моторы по [схеме сборки](docs/hardware.md).
2. На компьютере запустите `./manager/menu.sh`, введите адрес платы и выберите **Установить УМКУ и окружение**. Настройте отправку данных по [инструкции для новой платы](deploy/README.md).
3. Войдите как администратор на [сайт мониторинга](https://umka.technocrew.ru/) и нажмите **Добавить устройство**. Введите тот же ID, что и в настройках платы. Подробности есть в [инструкции по регистрации](web/README.md#добавить-устройство).
