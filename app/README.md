# Программа на устройстве

УМКА ждёт предмет, распознаёт его по камере и сбрасывает в нужную секцию. На экране видно, что распозналось. Для новой платы сначала выполните [установку](../deploy/README.md).

## Запуск и остановка

- **С автозапуском.** Включите плату. Если окно на дисплее не открылось, нажмите **Открыть экран UMKA** на рабочем столе.
- **Без автозапуска.** Нажмите **Запустить UMKA**, затем **Открыть экран UMKA**. Вместо второго ярлыка можно открыть `http://IP-ПЛАТЫ:3000` в браузере.
- **Из терминала на плате без автозапуска.** Выполните команды ниже. Для остановки нажмите **Ctrl+C** в этом же терминале. Если служба уже запущена, используйте команды для службы.

```bash
cd ~/app
.venv/bin/python app.py
```

Если при установке указали `--autostart`, программой управляет служба `umka`. В терминале на плате выполните нужную команду:

```bash
sudo systemctl start umka       # запустить
sudo systemctl restart umka     # перезапустить после изменения настроек
sudo systemctl stop umka        # остановить
systemctl status umka           # проверить состояние
```

Кнопка **Закрыть экран** закрывает только полноэкранное окно. Для остановки самой сортировки остановите программу или службу.

## Меню устройства

Коснитесь логотипа **пять раз за четыре секунды**. Меню появится по центру экрана. В нём есть настройки, выбор модели, сбор датасета, демонстрация и отладка. Через 15 минут без действий меню закроется.

### Выбрать модель

1. Откройте **Выбор модели**.
2. Выберите модель из списка и нажмите **Применить модель**.
3. Дождитесь, пока её имя появится рядом со словом **Активна**. Нажмите **Готово**.

Штатная модель — `best.pt` (AISB 3.2). В списке также есть AISB 3.0 и 3.1b. Свою модель формата `.pt` положите на плате в `~/app/data/models/`. При возврате на экран сортировки и после перезапуска УМКА использует выбранную модель.

### Собрать снимки

1. Выберите **Сбор датасета** → **Приостановить сортировку и начать сбор**.
2. Дождитесь изображения с камеры. Выберите память устройства или флешку. Если вставили флешку только что, нажмите **Обновить носители**.
3. Положите один предмет, выберите его категорию и нажмите **Сохранить снимок**.
4. После последнего снимка уберите предмет и нажмите **Вернуться к сортировке**. Если вкладка закрылась, снова откройте сбор датасета и нажмите эту кнопку.

Флешка должна быть открыта системой и доступна для записи. Снимки на ней лежат в папке `umka-dataset`. Снимки в памяти платы лежат в `~/app/data/dataset/manual`. Их можно скачать архивом в разделе **Настройки → Датасет**. Для обучения модели потребуется разметить рамки предметов на ручных снимках.

### Настроить сортировку

В меню **Настройки** можно проверить камеру, выбрать область распознавания, снять пустую площадку и настроить моторы. Пока открыты настройки, автоматический сброс приостановлен. После калибровки нажмите **Сохранить углы**, затем **Готово**.

В меню **Демонстрация** показывается изображение с рамками вокруг распознанных предметов. Посетительский экран доступен по адресу `http://IP-ПЛАТЫ:3000/`.

## Проверка камеры и моторов

Остановите сортировку перед проверкой, чтобы утилиты могли открыть камеру и контроллер моторов. Выполняйте команды на плате из каталога `~/app`, по одной за раз.

| Команда | Что проверяет |
| --- | --- |
| `.venv/bin/python tools/check_camera.py` | Снимок и яркость изображения |
| `.venv/bin/python tools/check_servo.py --channel 0` | Мотор на выбранном канале |
| `.venv/bin/python tools/calibrate.py` | Центр и сброс в секции |

Перед движением моторов прочитайте [порядок проверки оборудования](../docs/hardware.md#проверить-оборудование).

<details>
<summary>Где искать настройки, данные и параметры запуска</summary>

- `~/app/umka.conf` — настройки платы и подключения к мониторингу.
- `~/app/data/` — статистика, калибровка, снимки и журналы. Например, `sort_stats.json` содержит счётчики, а `events/events.jsonl` — сортировки и ответы.
- `~/app/data/logs/umka.log` — сообщения программы. При работе службой их также показывает `journalctl -u umka -n 50`.
- `.venv/bin/python app.py --help` — параметры запуска. Режим `--hardware console` имитирует сброс без движения моторов и по-прежнему использует камеру.
- `http://IP-ПЛАТЫ:3000/api/health` — статус камеры и модели. Состояние экрана и счётчики есть в `/api/state`.

</details>
