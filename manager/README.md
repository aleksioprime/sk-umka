# Управление УМКОЙ по SSH

Откройте терминал на компьютере в той же сети, что и плата. Из папки проекта запустите:

```bash
./manager/menu.sh
```

Введите адрес, например `umka@192.168.10.60`. Если подходит обычное подключение
по SSH, нажмите Enter в полях ключа и порта. В меню введите номер нужного
действия и нажмите Enter. Для выхода введите `0`.

- **1. Установить УМКУ и окружение** — поставить программу и её зависимости, включить автозапуск.
- **2. Обновить файлы программы** — загрузить новый код с сохранением данных и настроек платы.
- **6. Проверить плату и состояние** — посмотреть модель платы, состояние службы и адрес экрана.
- **7. Посмотреть журнал** — открыть последние сообщения УМКИ.
- **9. Подключить к мониторингу** — задать ID и параметры MQTT на плате.

Адрес, ключ и порт можно сразу передать в команде:

```bash
./manager/menu.sh umka@192.168.10.60 --ssh-key ~/.ssh/umka --port 2222
```

Для установки понадобятся Bash и SSH на компьютере, доступ к плате и права
`sudo` на ней. Меню запускает [установщик](../deploy/install.sh) из того же
репозитория. Подготовку новой платы и подключение к мониторингу см. в
[инструкции по установке](../deploy/README.md).

## Подключить к мониторингу

1. Выберите пункт **9. Подключить к мониторингу** и введите постоянный ID устройства.
2. Проверьте адрес брокера, порт, настройку TLS и логин. Enter сохраняет значение в скобках. Для новой платы предложены адрес `mqtt.skolhub.ru`, порт `8883`, TLS `yes` и логин `umka`.
3. Введите пароль, который дал администратор. Символы пароля на экране скрыты. При прежних адресе, порте, TLS и логине можно нажать Enter, чтобы сохранить установленный пароль. При смене подключения введите пароль для нового брокера.
4. Меню запишет настройки в `~/app/umka.conf` на плате и перезапустит службу `umka`. Для программы, запущенной вручную, перезапустите её из терминала.
5. Укажите этот же ID при [регистрации устройства на сайте](../web/README.md#добавить-устройство).

В `umka.conf` знак `#` начинает комментарий, поэтому меню отклоняет логины и пароли с этим знаком.
