# Подключить камеру и моторы

Для сборки понадобятся Raspberry Pi 4/5 или Orange Pi 5/5B, USB-камера, контроллер PCA9685, два сервопривода и отдельный блок питания для моторов. Экран по HDMI нужен только для показа интерфейса на самой УМКЕ.

## Подключить контроллер моторов

Выключите питание платы и моторов перед подключением. Номера в таблице — физические контакты разъёма платы.

| Контакт платы | Контакт PCA9685 |
| --- | --- |
| 1 (3,3 В) | VCC |
| 3 | SDA |
| 5 | SCL |
| 6 (земля) | GND |

1. Подключите плюс отдельного блока питания моторов к **V+**, минус — к **GND** контроллера. Земля у платы и контроллера общая. **V+ нельзя соединять с VCC или питанием платы.**
2. Соедините **OE** с землёй. Оставьте перемычки адреса **A0–A5** открытыми. Тогда адрес контроллера будет `0x40`.
3. Подключите мотор поворота к **каналу 0**, мотор наклона — к **каналу 1**. Сигнал идёт на **S/PWM**, питание — на **V+**, земля — на **GND**. Если каналы уже переставлены, задайте `rotate_channel` и `tilt_channel` в `~/app/umka.conf`.

Блок питания должен подходить к вашим моторам по напряжению и выдерживать нагрузку от обоих. Слабое питание может вызвать дрожание моторов и отключение камеры.

## Подключить камеру и экран

- Камеру подключите напрямую в USB-порт платы.
- Для изображения подключите HDMI. Если экран сенсорный, соедините его разъём **Touch** с платой USB-кабелем, который передаёт данные.

## Проверить оборудование

1. [Установите программу](../deploy/README.md) и выполните перезагрузку, если её попросил установщик.
2. На Raspberry Pi выполните `/usr/sbin/i2cdetect -y 1`, на Orange Pi 5/5B — `/usr/sbin/i2cdetect -y 5`. В таблице должен появиться адрес `40`. Если его нет, проверьте проводку и питание.
3. Остановите УМКУ, затем [запустите проверку каждого мотора](../app/README.md#проверка-камеры-и-моторов) на его канале. Сначала проверяйте мотор отдельно от механизма. Команда `s` проходит весь диапазон, `off` отключает сигнал. На собранном механизме подбирайте углы небольшими шагами, чтобы мотор не упёрся в корпус.
4. Пока УМКА остановлена, проверьте камеру той же [инструкцией](../app/README.md#проверка-камеры-и-моторов). Утилита сохранит снимок в `~/app/data/camera-check.jpg`.
5. Запустите УМКУ. В меню **Настройки → Центр** задайте положение покоя. Во вкладке **Секции** настройте углы для четырёх секций и нажмите **Проверить сброс** для каждой.
6. Нажмите **Сохранить углы**. Настройте **Область распознавания** и снимите **Пустую площадку**, затем нажмите **Готово**. Откройте **Демонстрация** и убедитесь, что рамка появляется на предмете.

<details>
<summary>Дополнительные сведения для сборки</summary>

- Orange Pi 5/5B использует шину I2C 5 с настройкой `i2c5-m3`. UART1 на этих контактах должен быть выключен.
- Вариант без PCA9685 для Raspberry Pi использует GPIO 12 для наклона и GPIO 13 для поворота. Выберите `hardware = gpiozero`.
- Для Orange Pi 5B с экраном 1024×600 см. [решение проблем с HDMI](troubleshooting.md#экран).

</details>
